# 📊 Employee Attrition Dashboard  

An interactive dashboard designed in **Excel** to analyze **employee attrition trends** and provide insights into workforce stability, turnover, and retention.  

This project highlights skills in **HR Analytics, KPI tracking, Excel dashboards, and storytelling with data**.  

---

## 📌 Overview  

The purpose of this project is to help HR teams and managers understand:  
- Which departments and demographics are most affected by attrition.  
- How attrition trends have changed over time.  
- Key workforce metrics such as **Attrition Rate** and **Average Tenure**.

## 🔎 Key Features  

- **KPI Cards**:  
  - Total Employees  
  - Active Employees  
  - Attrition Rate (%)  
  - Average Tenure  

- **Filters** for interactive analysis:  
  - Recruitment Source  
  - Performance Score  
  - Department  

- **Visualizations**:  
  - Attrition Rate by Gender  
  - Attrition by Department  
  - Attrition Trend (Year-wise)  
  - Attrition by Marital Status  
  - Attrition by Performance Score  
  - Attrition Rate by Race  

---

## 📈 Key Insights  

- **Production Department** has the highest attrition (83 employees).  
- Majority of attrition comes from **Married employees** (47).  
- **Fully Meets** performance group has the largest attrition (81).  
- Attrition is higher among **Male employees** compared to Female.  
- Average employee tenure is **9.17 years**.  
- Attrition trend peaked in **2015–2016** before declining.
